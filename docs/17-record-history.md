# Record History

Passhub keeps a history of record changes. Each time you edit an existing record, its previous state is preserved and can be accessed in the record dialog. Click the **History** icon to view the full history sorted by date; the top entry in the list is the current data.

When viewing previous versions, all operations (edit, copy, move, delete) are disabled. To modify record fields, switch to the current version (the top item in the history list). When you copy, move, or drag-and-drop a record, its history is copied or moved as well.
